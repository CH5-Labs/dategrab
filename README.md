# 📅 DateGrab – Web to Google Calendar

> *Clean, Creative Code Crafted by Carl — by **CH5 Labs***

**DateGrab** is a lightweight browser extension that scans any webpage using Google Gemini AI, extracts upcoming dates, times, locations, and direct event links, and generates one-click **Google Calendar** links.

## ✨ Features
* **One-Click Date Extraction:** Automatically detects upcoming events from concert schedules, timetables, and tables.
* **Smart Event Links:** Links directly to the specific event subpage when available.
* **Multi-Language:** Outputs event titles and descriptions in the same language as the webpage.
* **Privacy-First:** Uses your own free Google Gemini API key stored locally in your browser (`chrome.storage.local`).
